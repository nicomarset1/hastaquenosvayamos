# Hasta Que Nos Vayamos

Página web base para la radio "Hasta Que Nos Vayamos" (Mar del Plata).

## Contenido

- `index.html` — estructura de la página (inicio, reproductor, locutores, contacto)
- `style.css` — estilos, con la paleta e identidad del brand kit
- `script.js` — comportamiento del formulario de contacto
- `assets/` — logo y elementos gráficos de la marca

## Uso

Es un sitio estático sin build. Abrí `index.html` en el navegador o desplegalo directamente (ej. Vercel).
